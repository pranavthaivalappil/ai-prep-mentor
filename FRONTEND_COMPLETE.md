## 🚀 How to Run the Complete MERN Stack

### Step 1: Setup MongoDB

**Option A: MongoDB Atlas (Cloud - Recommended)**
1. Go to https://www.mongodb.com/cloud/atlas
2. Create free account
3. Create a new cluster (free tier)
4. Click "Connect" → "Connect your application"
5. Copy the connection string
6. Update `backend/.env`:
```env
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/ai-interview-mocker?retryWrites=true&w=majority
```

**Option B: Local MongoDB**
```powershell
# Install MongoDB Community Edition
# Then start the service
net start MongoDB

# Update backend/.env
MONGODB_URI=mongodb://localhost:27017/ai-interview-mocker
```

### Step 2: Configure Backend Environment

Edit `backend/.env`:
```env
# MongoDB
MONGODB_URI=your_mongodb_connection_string_here

# JWT Secret (create a random string)
JWT_SECRET=my_super_secret_jwt_key_12345_change_in_production

# Gemini AI (use your existing key)
GEMINI_API_KEY=AIzaSy...

# Razorpay (use your existing keys)
RAZORPAY_KEY_ID=rzp_test_...
RAZORPAY_KEY_SECRET=...

# Server
PORT=5000
NODE_ENV=development
FRONTEND_URL=http://localhost:5173
```

### Step 3: Configure Frontend Environment

The `.env` file in frontend is blocked, so create it manually:

```env
VITE_API_URL=http://localhost:5000/api
VITE_RAZORPAY_KEY_ID=rzp_test_...
```

### Step 4: Start Backend

```powershell
# Terminal 1 - Backend
cd backend
npm run dev
```

You should see:
```
✅ MongoDB Connected: ...
🚀 Server running on port 5000
📡 API Base URL: http://localhost:5000/api
```

### Step 5: Start Frontend

```powershell
# Terminal 2 - Frontend (new terminal)
cd frontend
npm run dev
```

You should see:
```
  VITE v7.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### Step 6: Test the Application

1. Open browser: http://localhost:5173
2. Click "Get Started" to sign up
3. Create an account
4. Create a new interview
5. Take the interview
6. View feedback

## 🐛 Common Issues & Solutions

### Issue: "Cannot connect to backend"
**Solution:**
- Check if backend is running on port 5000
- Verify VITE_API_URL in frontend/.env
- Check browser console for CORS errors

### Issue: "MongoDB connection error"
**Solution:**
- Verify MongoDB is running (local) or connection string is correct (Atlas)
- Check if IP is whitelisted in MongoDB Atlas
- Ensure MongoDB URI is correct in backend/.env

### Issue: "Questions not generating"
**Solution:**
- Verify GEMINI_API_KEY is set in backend/.env
- Check backend console for Gemini API errors
- Ensure API key is valid and has proper permissions

### Issue: "Login not working"
**Solution:**
- Check if JWT_SECRET is set in backend/.env
- Verify backend is running
- Check browser console and network tab for errors

## 🚀 Deployment Guide

### Backend Deployment (Railway/Render)

**Railway:**
```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Initialize
railway init

# Add environment variables in Railway dashboard
# Deploy
railway up
```

**Render:**
1. Go to https://render.com
2. Click "New" → "Web Service"
3. Connect GitHub repository
4. Set build command: `cd backend && npm install`
5. Set start command: `cd backend && npm start`
6. Add environment variables
7. Deploy

### Frontend Deployment (Vercel/Netlify)

**Vercel:**
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
cd frontend
vercel
```

**Netlify:**
1. Go to https://netlify.com
2. Click "Add new site" → "Import from Git"
3. Connect GitHub repository
4. Set build command: `cd frontend && npm run build`
5. Set publish directory: `frontend/dist`
6. Add environment variable: `VITE_API_URL=your_backend_url`
7. Deploy
